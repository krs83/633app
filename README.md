# Номера 633

Приложение для учёта автомобильных номеров с поиском по базе.

## Возможности

- Список номеров с автоматической сортировкой по алфавиту
- Добавление нового номера
- Удаление долгим нажатием (с подтверждением)
- Нормализация формата
- Данные сохраняются локально (SQLite)

## Стек

- Flutter
- sqflite — локальная БД
- path — работа с путями
